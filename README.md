# 三國武將倖存者（暫名）— 網頁原型

單一武將＋少量部隊，對抗倖存者式的海量敵軍。色塊美術，用來驗證手感、效能、招降玩法。

## 怎麼玩
- 用瀏覽器開 `index.html`（需要用本機伺服器，例如 `python3 -m http.server`，再開 http://localhost:8000）。
- 移動：WASD／方向鍵；手機在畫面左半邊拖曳。
- 武將技：殺敵集氣，滿了按空白鍵或右下「武將技」。
- 升級：點卡片或按 1～3。
- 網址加 `?debug` 會顯示 FPS 和單位數量。

## 原型內容（第 1 版）
- 主將：關羽，自動往面向揮出扇形橫掃（站著不動時面向最近的敵人）。
- 部隊（少量）：弓手 2（主將身後一排，自動射最近的敵人）、騎兵 2（兩翼，自動往敵人衝鋒穿刺再回位）。陣亡 12 秒後補回。
- 副將：第 1:40 出現黃巾猛將「周倉」，擊敗後可選擇招降（跟隨作戰、定期大刀旋風斬）或放走換經驗。
- 敵軍：黃巾兵、黃巾刀兵、黃巾力士，數量隨時間增加，同時最多 1400 隻。
- 升級三選一：武將（刀勢、偃月、青龍、迅刀、回馬刀、武聖之怒）、屬性（虎體、赤兔、養氣、軍需）、部隊（增募弓手、增募騎兵、連弩、火矢、鐵騎、軍醫）。
- 武將技「青龍偃月斬」：立繪特寫（目前是色塊佔位）＋大範圍清場。
- 撐過 8 分鐘勝利。

## 檔案
- `src/config.js`：所有數值（調手感、難度只改這裡）。
- `src/upgrades.js`：升級卡池。
- `src/main.js`：遊戲本體（輸入、單位、空間格子碰撞、繪圖）。

## 效能
敵人用空間格子（40 像素一格）做碰撞與範圍查詢；只畫畫面內的單位。目前 1300 隻敵人仍維持 60 FPS（桌機無頭瀏覽器測試）。
